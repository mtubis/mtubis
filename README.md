## 🚀 Featured Project

### [HTML Translator](https://github.com/mtubis/html-translator)

**An open-source PHP library for translating HTML with LLMs while preserving document structure and validity.**

Available on [Packagist](https://packagist.org/packages/mtubis/html-translator):

```bash
composer require mtubis/html-translator
```

The library supports OpenAI, Anthropic, Gemini and self-hosted models through a provider-independent architecture.

Key engineering aspects:
- HTML-aware segmentation and structure validation
- Provider abstraction built around PSR interfaces
- Translation profiles, glossary and terminology control
- Resilient handling of partial failures, retries and fallback strategies
- Caching, batching and token usage considerations
- Automated tests, static analysis and CI/CD
- Documented architectural decisions (ADRs)

**Tech:** PHP 8.4 · Composer · PSR-18 · PHPUnit · PHPStan · GitHub Actions · LLM APIs

The project is actively evolving toward a stable 1.0 release.
